# Apple Music Organizer

Apple Music のプレイリストを読み取り、重複候補を表示するブラウザ用プロトタイプです。曲を削除・変更する機能はありません。

## ファイル

- `index.html` — 画面と MusicKit JS の読み込み
- `app.js` — 認証、ライブラリのプレイリスト取得、重複候補の検出
- `style.css` — レスポンシブな画面デザイン
- `.gitignore` — 秘密鍵や環境ファイルを Git に追加しないための設定

## 現状と必要な準備

このリポジトリは**初期プロトタイプ**です。Apple Music と接続するには、Apple Music API 用の有効な Developer Token が必要です。また、ライブラリへのアクセスには MusicKit JS によるユーザー認証・許可が必要です。

1. Apple Developer の公式資料で MusicKit / Apple Music API の現在の登録要件を確認してください: https://developer.apple.com/musickit/
2. Developer Token は Apple の公式手順で生成します。トークン生成に使う秘密鍵（通常 `.p8`）を、このリポジトリ、ブラウザ側コード、チャットに絶対に置かないでください。
3. `index.html` を HTTPS 対応の静的ホスティングで公開します（GitHub Pages など）。学校のネットワークでは外部スクリプトや Apple Music への通信がブロックされる可能性があります。
4. 公開サイトを開き、Developer Token を画面に入力して「Apple Musicに接続」を選択し、Apple Music の認証画面で許可します。
5. 「ライブラリを読み込む」→対象プレイリストを選択→「重複をチェック」を実行します。

## セキュリティ

- Apple ID のパスワードや認証コードを、このツールに入力しないでください。Apple の認証画面だけを使ってください。
- `.p8` 秘密鍵、署名用キー、個人用アクセストークンをコミットしないでください。
- Developer Token は秘密鍵そのものではありませんが、共有・公開を避け、必要な範囲でのみ使ってください。
- このプロトタイプはライブラリの読み取りのみを行い、曲の削除や変更はしません。
- 重複判定は候補提示です。タイトルとアーティストが同じ別録音・別バージョンが候補に含まれる可能性があります。

## 制限事項

- ChatGPT と直接連携する MCP サーバーはまだ含まれていません。現状はブラウザで開いて使うツールです。
- ChatGPT から直接使うには、別途 ChatGPT が利用できるカスタムアプリ/MCP サーバーと安全なホスティング、認証設計が必要です。利用可否は ChatGPT のプランと設定に依存します。
- Apple Developer Program への加入やトークン生成の要件は Apple の最新公式情報で確認してください。未加入の状態で API 接続できると保証するものではありません。
- 初期版なので、Apple Music API のレスポンスやページネーションの仕様により調整が必要になる場合があります。

## プライバシー

この静的プロトタイプには、入力したトークンをブラウザのストレージへ保存するコードはありません。ページを閉じると画面上の入力は消えます。ただし、ブラウザ・ホスティング・Apple 側の通常の通信処理は別途適用されます。
